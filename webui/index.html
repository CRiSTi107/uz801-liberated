Change IMEI (funcNo 2002)

Writes the modem IMEI via AT+WRIMEI. Changing the IMEI of a device may be illegal in your jurisdiction and can disrupt network registration. The modem usually needs a reboot/CFUN cycle for the new value to take effect. Use only on your own hardware.

IMSI and ICCID are stored on the SIM card itself and cannot be changed on the device — they belong to the SIM, not the modem. To change them you need a programmable (sysmo/writable) SIM.

Advanced AT commands

Arbitrary modem AT commands (beyond IMEI) are not exposed over the web API and this device's lightweight web server has no CGI. Run them over USB adb instead:

adb shell modem_at "AT+CGSN"      # read IMEI
adb shell modem_at "AT+WRIMEI=<imei>"   # write IMEI
adb shell modem_at "AT\$QCRSRP?"   # LTE RSRP / cell/band

USB debug / root ADB (funcNo 2001)

Danger. This switches the USB composition to rndis,serial_smd,diag,adb and exposes a root ADB shell over USB. Only do this if you understand the risk. Revert on-device with setprop persist.sys.usb.config rndis + reboot.
